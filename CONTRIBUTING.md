# 🤝 Contributing to Fluent-Steam-Lua

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [huanyuejue/Fluent-Steam-Lua](https://github.com/huanyuejue/Fluent-Steam-Lua). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/NEVARLeVrai/Fluent-Steam-Lua.git

## ✅ Verify your changes

Follow the README's Windows build setup. Include an example and test the affected WPF screen using local test data.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
